# .codex/

Дополняет `AGENTS.md` (его Codex CLI загружает из корня репо автоматически сам, без
отдельной команды). Здесь то, что `AGENTS.md` не обязан нести сам — рабочий контекст,
который не меняется от плана к плану.

У Codex нет собственной долговременной памяти между сессиями (в отличие от Claude —
у него она есть, см. `knowledge.md`). Если `knowledge.md` когда-то выглядит пустым или
устаревшим, смотри живой источник, а не эту копию: он может быть обновлён позже, чем
этот файл.

Роль Codex в этом репо — adversarial Plan-Reviewer, см. `AGENTS.md` → «Роль:
Plan-Reviewer».
