# База знаний

Сюда загружаются транскрибации роликов и PDF-материалы к ним.

Правило именования — одинаковое имя для пары:

- `01-название.txt` — транскрибация ролика
- `01-название.pdf` — PDF к этому ролику

Как загрузить: на GitHub откройте эту папку → **Add file → Upload files** →
перетащите файлы → **Commit changes**.
